## 💻 Desafios Resolvidos

### 1. Cálculo de Média Escolar
- **Arquivo:** [`desafio-media-aluno.js`](./desafio-media-aluno.js)
- **Linguagem:** JavaScript
- **Conceitos Praticados:**
  - Entrada e saída com `gets()` e `print()`
  - Estruturas de controle condicional (`if`, `else if`, `else`)
  - Operador lógico AND (`&&`)
- **Regras de Negócio:**
  - Média `< 5`: `REP`
  - Média `>= 5` e `< 7`: `REC`
  - Média `>= 7`: `APR`

---

### 2. Maior Número Par e Menor Número Ímpar
- **Arquivo:** [`desafio-maior-par-menor-impar.js`](./desafio-maior-par-menor-impar.js)
- **Linguagem:** JavaScript
- **Conceitos Praticados:**
  - Laço de repetição `for`
  - Operador módulo `%` para identificar par/ímpar
  - Igualdade estrita `===` vs igualdade solta `==`
  - Uso do `else` para evitar testes redundantes
  - Valor inicial `Infinity` como sentinela para mínimo
  - Concatenação de texto com variável usando `+`
- **Regras de Negócio:**
  - Lê N números da entrada
  - Imprime o maior número par encontrado
  - Imprime o menor número ímpar encontrado
- **Lição aprendida:** O texto de saída deve ser copiado **exatamente** do enunciado — um acento a mais quebra o teste automático!
